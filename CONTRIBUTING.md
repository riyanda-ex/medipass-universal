# Kontribusi

## Aturan Mutlak
1. JANGAN PERNAH upload data pasien asli (nama, NIK, No. RM, No. BPJS, foto KTP, PDF rekam medis).
2. Gunakan data sintetis: `PASIEN-001`, tanggal lahir contoh, kontak `+628123456789`.
3. Semua perubahan harus lolos `python test.py` - wajib 20/20.
4. Satu PR untuk satu fitur / perbaikan.
5. Jangan ubah logika enkripsi tanpa review keamanan.

## Cara
1. Fork repo ini
2. Buat branch: `git checkout -b tambah-fitur`
3. Jalankan test: `python test.py`
4. Buat Pull Request dengan deskripsi jelas
